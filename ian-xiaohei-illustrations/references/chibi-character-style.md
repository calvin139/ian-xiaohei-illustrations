# Chibi Character Icon Style Guide

## 一句话定位

柔和水彩感手绘风格的 Chibi 角色头像。大头小身体、半睡眠表情、技术主题、极简设计、适合 GitHub 头像。

## 核心视觉特征

### 身体比例
- **头身比**：头部占画面 50-60%，夸张大头小身设计
- **头部**：圆润、柔和、非几何形
- **身体**：最小化，简洁线条，通常 1/3-1/4 头部尺寸
- **表情**：半眯眼、轻微困倦感、镇定自信、神秘感

### 画风特征
- **笔触**：柔和笔刷、可见笔画、非矢量、非干净线稿
- **纹理**：半水彩感、半透明笔触、柔边效果
- **背景**：纯白或极淡背景（方形 1:1 格式）
- **阴影**：柔和漫射光、温和高光、无硬阴影
- **边缘**：软边、柔和过渡、略显"手绘"感

### 色彩调性
- **主色调**：冷色系为主，蓝色、青色、柔和紫色
- **调性**：柔和饱和度降低的粉彩色
- **对比**：低对比度，舒适柔和
- **特色色**：可用少量暖色点缀（金色、橙色微光）

## 必需设计元素

### 1. 发型
- 短发、略微蓬乱、分层结构
- 柔和边缘，避免刚硬线条
- 可以有微微向上翘的发丝
- 整体 2-3 个层次的厚度变化

### 2. 头部配饰（技术主题）
- **创意耳机/头戴式配饰**：完全原创设计，基于技术元素
  - 可融入数字线条、电路感元素（但要柔和化处理）
  - 可有微弱的发光效果（蓝色或紫色）
  - 不能是真实品牌的临摹
- **抽象动物元素（可选）**：
  - 不是标准的猫耳、兔耳
  - 可以是重新设计的抽象形状
  - 融入角色整体设计，不显得突兀

### 3. 眼部
- 半眯眼：上眼睑盖住瞳孔的 1/3-1/2
- 瞳孔可略显光泽
- 表情传达：放松、镇定、略显神秘
- 眼睛大小约为脸部宽度的 1/4-1/3

### 4. 浮动装饰元素
- 角色周围 3-5 个小元素
- 可以是：符号、抽象形状、数字图案、UI 元素、技术图标
- 大小差异明显（1/5 到 1/10 角色大小）
- 位置：不遮挡角色，周围空间分布
- 透明度可略低于主体（30-50% 透明度）
- 配色与主体协调

### 5. 技术/黑客主题元素
- 微妙的技术感，不是漫天二进制和代码
- 可包含：
  - 最小化 UI 细节（如细线框、小圆点）
  - 抽象的数字图案
  - 代表"网络"的连接线（极简）
  - 发光效果（蓝/紫色微光）
  - 极客美学暗示，不直白表达

## 绝对禁止

- 不要参考现有 IP（如皮卡丘、Hello Kitty、任何知名角色）
- 不要复制艺术家风格
- 不要过度复杂、细节过多
- 不要使用真实品牌的耳机/配饰
- 不要商业矢量风格
- 不要高对比度、鲜艳颜色
- 不要光滑、3D 效果
- 不要真实阴影
- 不要背景过复杂

## 可读性要求

- 在 64x64px 大小下仍清晰可认
- 主体颜色与背景有足够对比度
- 发型和配饰轮廓清晰
- 面部表情在缩小后仍可识别

## 应用场景

- GitHub 用户头像（方形 1:1 格式）
- 社交媒体头像
- 个人品牌代表
- 开发者身份标识
